# School Management System

A web-based School Management System built using Flask and SQLite.

## Features

- Admin, Teacher, and Parent login
- Admin can add students, parents, and teachers
- Homework, marks, attendance, notices, and activities
- Teacher dashboard for homework and marks
- Parent dashboard with student details
- Parents can submit complaints
- Colorful and responsive user interface

## User Roles

### Admin
- Manage students, teachers, homework, marks, attendance, notices, and activities
- View and update parent complaints

### Teacher
- Add homework
- Add marks

### Parent
- View student details
- View homework, attendance, marks, notices, and activities
- Submit complaints

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run

1. Install Flask:

```bash
pip install flask
```

2. Run the application:

```bash
python app.py
```

3. Open in browser:

```text
http://127.0.0.1:5000
```
